
# VidLearn

1. create .env file in backend folder
Update mongo db credential as given in env.example

2. run `npm install` in both folder backend and frontend

3. to run backend `npm run start`

4. to run frontend `npm run dev`

5. for backend admin login please run command for data seed `npm run seed:admin`

5. backend api should be running on port 5000 by default

6. frontend url will be http://localhost:5173 by default

7. postman collection is added in root directory of this repo
